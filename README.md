# KAIRO Opportunity Ranking v0.9

Advisory-only multi-factor opportunity ranking for the existing KAIRO shortlist.

## Added

- `KAIRO-ORANK-1.0` deterministic ranking methodology
- `/api/opportunity-ranking` authenticated endpoint
- `/opportunity-ranking` frontend route and sidebar entry
- Ten transparent weighted components totalling 100 points
- Conservative confidence calibration from measured confidence bands
- Historical-similarity and measured-return integration
- Symbol/sector performance and sample-maturity weighting
- Positive contributors, penalties and rank-improvement guidance
- Backend, API and frontend tests

No order submission, risk-policy or execution-gate behaviour is changed.
